# Консоль разработчика

Открыть и закрыть: «ё» (физическая клавиша под Esc, также `~` в английской раскладке). Закрыть можно и Esc. Enter выполняет команду; ↑/↓ листают историю. После самой новой записи ↓ возвращает недописанную строку.

Команды:

| Команда | Назначение / пример |
|---|---|
| `help` / `help hp` | Список команд / подробности одной команды |
| `restart` | Пересоздать текущую сцену из исходного файла |
| `exit` | Закрыть игру |
| `hp 75` | Установить текущее HP; 0 убивает, положительное значение оживляет |
| `max_hp 200` | Изменить максимум HP; текущее значение ограничивается максимумом, автоматически не заполняется |
| `stamina 100` | Установить текущую стамину |
| `max_stamina 200` | Изменить максимум стамины |
| `stamina_drain false` | Бег без расхода стамины и без ограничения её запасом; `true` возвращает расход |
| `stamina_regen 30` | Восстанавливать 30 единиц стамины в секунду; 0 отключает восстановление |
| `stamina_enabled false` | Отключить систему стамины и скрыть индикатор; запас сохраняется, бег доступен без него |
| `sprint_enabled false` | Отключить бег; `true` включает его обратно |
| `sprint_speed 500` | Скорость бега в пикселях/с; обычная ходьба не меняется |
| `build_speed 2` | Строительство и появление сегментов вдвое быстрее; 1 — обычная скорость |
| `demolition_speed 2` | Кувалда и отвёртка вдвое быстрее, включая очереди |
| `build_instant true` | Строительство без задержки |
| `demolition_instant true` | Демонтаж без задержки |
| `build_range 200` | Радиус достройки от края объекта, пиксели; чертежи по-прежнему можно размещать издалека |
| `demolition_range 100` | Радиус кувалды и отвёртки от края объекта |
| `cutter_range 200` | Радиус кусачек |
| `build_range_enabled false` | Отключить ограничение дальности достройки |
| `demolition_range_enabled false` | Отключить ограничение дальности всех трёх инструментов |

Команды настроек без аргумента показывают текущее значение. Для переключателей доступны только `true` / `false`. Текущее HP и стамина должны находиться в пределах своего максимума; максимумы — 1…1000000; скорость бега — 1…10000; восстановление — 0…1000000. Неверные аргументы не меняют состояние. Настройки строительства и инструментов действуют и на текущие работы. Множители скорости: 0,01…1000, дистанции: 1…100000 пикселей. Мгновенный режим не отменяет ограничение дальности: оно отключается отдельно. Отключение дальности не убирает стены и не разрешает строить на занятом месте. Все настройки действуют только до перезапуска сцены.

Во время ввода дерево игры приостановлено. Закрытие консоли возвращает прежнее состояние паузы и открытых меню. Журнал и история принадлежат Autoload DeveloperConsole и сохраняются после restart в пределах текущего запуска игры. Лимиты: 300 записей журнала и 100 команд истории.

Известная команда подсвечивается голубым, неизвестная — красным. Аргументы имеют отдельный цвет, строки в кавычках — зелёный, числа — оранжевый. Количество и значения аргументов проверяются; неправильный ввод выводит ошибку, не выполняя действие.

## Как добавить команду

Основные файлы:

- `scripts/console_command_registry.gd`: регистрация, разбор строки, проверка количества аргументов и вызов обработчика.
- `scripts/console_syntax_highlighter.gd`: подсветка на основе того же разбора строки.
- `scripts/developer_console.gd`: интерфейс, история, журнал, help, restart и exit.
- `scripts/player_console_commands.gd`: команды настройки персонажа.
- `scripts/building_console_commands.gd`: настройки строительства и инструментов.

В `register_builtin_commands()` зарегистрировать обработчик:

```gdscript
registry.register_command("command_name", _command_name, "Описание", 1, 2, "command_name <required> [optional]")
```

Обработчик получает `PackedStringArray` и возвращает результат:

```gdscript
func _command_name(args: PackedStringArray) -> Dictionary:
    # Проверить значения аргументов и применить действие.
    return {"ok": true, "message": "Готово: %s" % args[0]}
```

Параметры регистрации: имя, Callable, описание, минимум аргументов, максимум аргументов (`-1` — без ограничения), строка использования. Реестр проверяет количество аргументов; проверка их значений остаётся в обработчике. Поддерживаются одинарные/двойные кавычки и экранирование обратной косой чертой. Консоль выполняет только явно зарегистрированные обработчики.

`DeveloperConsole.write_log(message, "result")` добавляет сообщение в журнал; для ошибки использовать тип `"error"`. Текст добавляется как обычный текст, без интерпретации BBCode.

## Проверки

```text
godot --headless --path . --script res://tests/test_developer_console.gd
godot --headless --path . --script res://tests/test_developer_console.gd -- --exit-test
```

Первый запуск проверяет реестр, подсветку, историю, паузу, меню и фактический перезапуск сцены. Второй проверяет завершение процесса командой exit.

Проверка параметров персонажа и HUD: `res://tests/test_player_console_commands.gd`.

Проверка настроек строительства и демонтажа: `res://tests/test_building_console_commands.gd`.
