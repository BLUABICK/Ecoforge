## 2. Прямо сейчас: что нарисовать другу

Начать с маленького набора для проверки масштаба; не рисовать весь каталог до его утверждения.

| Приоритет | Объект | Первая версия | Что проверяем |
|---|---|---|---|
| 1 | Персонаж в космическом костюме | Один неподвижный спрайт сверху, без предметов в руках | Читаемость, размер, положение ног и столкновения |
| 2 | Одно пробное здание | Один спрайт сверху, прямоугольное основание 3×2 клетки | Размещение, поворот и масштаб относительно персонажа |
| 3 | Поверхность планеты | Один бесшовный тайл грунта | Повторение без швов, контраст с персонажем и зданиями |
| 4 | Контейнер | Один спрайт сверху и маленькая иконка | Понятность объекта хранения |
| 5 | Камень/обломок-препятствие | 1–2 простых варианта | Столкновения и читаемая граница объекта |
| 6 | Иконки тестовых предметов | Руда и известняк для проверки заполненных слотов | Читаемость при уменьшении; это предметы в инвентаре, а не поверхностные залежи |

Анимации на этом этапе не обязательны. Быстрый черновик лучше набора законченных рисунков, который потом придётся переделывать из-за масштаба.

### Предварительный формат передачи рисунков

- PNG с прозрачным фоном для персонажа, зданий, предметов и препятствий. Грунт — непрозрачный бесшовный PNG. Не использовать JPG для игровых спрайтов.
- Общий вид сверху, одинаковое направление света и согласованный стиль.
- Текущая клетка строительства — 32×32 игровых пикселя. Пробное здание 3×2 занимает 96×64. Для первого черновика подходит холст 96×64 без выступающих деталей; большие крыши/тени обсудим отдельно.
- Для персонажа предлагается первый холст 48×48; это стартовый ориентир, а не окончательный размер персонажа.
- Иконки предметов — одинаковый квадратный холст, например 64×64; проверять читаемость при показе в слоте 56×56.
- Названия латиницей: player_idle.png, test_module.png, ground_01.png, storage.png, rock_01.png, iron_ore.png, limestone.png.
- Реальные рисунки хранить в assets/sprites/ с подпапками player, buildings, terrain, items. Временные образцы агента — в tests/fixtures/.
- Исходники редактора сохранять отдельно от экспортированных PNG. Перед началом работы договориться, кто редактирует конкретную сцену/рисунок в Git.
- Одна картинка здания сейчас может поворачиваться движком на 90°. Четыре отдельных вида понадобятся только если рисованный свет, надписи или ракурс нельзя вращать вместе с картинкой.

## 4. Для первой миссии: полный минимальный список графики

Это список потребностей, а не требование рисовать всё прямо сейчас. Начинать объект после согласования его размеров и функции.

### Персонаж и инструмент

- [ ] Персонаж: ожидание и ходьба по четырём направлениям. Число кадров согласовать после статичного спрайта.
- [ ] Бег: сначала допускается более быстрое воспроизведение ходьбы; отдельную анимацию сделать при необходимости.
- [ ] Один прибор измерения: иконка, вид в руках/при работе, простой эффект сканирования.
- [ ] Иконки снаряжения только для реально реализованных предметов. Шесть инструментов и полный гардероб заранее не рисовать.

### Планета

- [ ] Базовый грунт и 2–3 варианта для разнообразия.
- [ ] Кислотно-загрязнённая и очищенная версии поверхности, переходы между ними.
- [ ] Вода и берег, если в выбранной миссии вода находится на поверхности.
- [ ] 2–3 препятствия/камня.
- [ ] Простая восстановленная растительность.
- [ ] Визуал подземного месторождения в режиме разведки/интерфейсе после согласования механики. Поверхностные рудные камни не нужны.

### Оборудование

- [ ] Один генератор — конкретный тип выбрать по климату первой планеты.
- [ ] Карьер — после согласования размеров, места установки и добычи.
- [ ] Насос.
- [ ] Контейнер для твёрдых материалов; ёмкость жидкости, если она нужна цепочке.
- [ ] Установка производства реагента.
- [ ] Очиститель территории.
- [ ] Исследовательская станция/датчик для данных, если это отдельное здание.
- [ ] Элементы соединений: провода, трубы или иной транспорт только после выбора системы логистики. Для сегментов понадобятся прямой участок, угол и необходимые разветвления.

Для каждого здания сначала статичный спрайт и иконка меню. Затем, если нужно для понимания работы, простой эффект активности и сигнал остановки. Не нужно заранее рисовать много уровней одного здания.

### Предметы и интерфейс

- [ ] Иконки сырья, воды, реагента, строительных материалов — по итоговому списку первой цепочки.
- [ ] Иконки зданий для каталога строительства.
- [ ] Изображение прибора для слота инструмента.
- [ ] При необходимости небольшие значки: нет энергии, нет входного ресурса, заполнен выход, загрязнение.
- [ ] Квадраты слотов, сетку, контуры, шкалы HP/стамины и панели отдельно рисовать не нужно: они уже строятся кодом.
- [ ] Простой экран контракта и результата можно сделать средствами интерфейса без отдельной иллюстрации.
