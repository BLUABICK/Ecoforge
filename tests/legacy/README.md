# Архив проверок автоматических соединителей

Эти проверки описывают отменённые перемычки и автоматические соединители труб/проводов. Они сохранены для истории и не входят в актуальный набор проверок.

Текущая механика проверяется в ../test_endpoint_placement.gd, ../test_wire_drawing.gd, ../test_pipe_drawing.gd и ../test_area_cutters.gd.
